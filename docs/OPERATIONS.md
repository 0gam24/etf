# 운영 목표와 작업 대기열 (Growth Operations)

시작: 2026-10-06 · 운영자 지시: "애드센스 일 100달러가 될 때까지 수익화를 위해 할 수 있는 모든 방법을 동원해서 계속 실행"

이 문서는 iknowhowinfo.com 의 **수익 목표, 그 목표까지의 산술, 쓸 수 있는 레버, 넘지 않는 선, 작업 대기열**을 한곳에 둔다. 매일 운영 작업(대화 세션·로컬 예약 작업)은 이 문서의 대기열 맨 위부터 처리하고, 끝나면 결과와 날짜를 남긴다. 발행 규칙은 [PUBLISHING.md](../PUBLISHING.md), 문체·보안·주제 선정은 [CLAUDE.md](../CLAUDE.md)가 우선한다.

## 2. 레버 (효과 큰 순)

1. **ETF 개체 데이터** (`/etf` 1,171종): 과거 구글 노출의 92~94%가 "상품명·코드 + 구성종목·분배금·종목코드·총보수" 검색이었다. 페이지마다 경쟁 사이트에 없는 고유 수치(같은 날 NAV·괴리율, 구성종목, 분배 이력, 총보수, 같은 지수 상품 비교)를 채울수록 이 검색을 다시 받는다. 시세는 GitHub Actions 가 매일 갱신한다.
2. **같은 지수 비교 페이지** (`/compare`): 같은 지수를 따르는 상품 사이의 선택 의도. 실제 클릭이 난 유형(비교·판단)이다.
3. **ETF 전용 계산 도구** (`/tools`): 도구 검색은 수요가 크고 반복 방문이 생긴다. 형제 사이트 calculatorhost 실측에서 도구 페이지는 가이드보다 쪽당 노출이 약 6.6배였다.
4. **크롤 회복**: 구글이 7월 말부터 새 주소를 크롤하지 않는다(9월 가이드 31편 미크롤). sitemap·RSS 의 404 제거, 같은 지수 상품끼리의 내부 링크, 얇은 페이지 정리로 크롤 수요를 되살린다.
5. **네이버**: 08월 노출 6.8만으로 구글보다 큰 채널이었다. 제목·요약 문구, 서치어드바이저 신호를 네이버 검색 결과에 맞춘다.
6. **수익화 배치**: 트래픽이 생긴 페이지부터 수동 광고 단위(본문 중간·표 아래)를 더해 페이지당 수익을 올린다. 광고 단위 ID 는 운영자가 AdSense 콘솔에서 만든다.
7. **재방문**: RSS·웹푸시 구독, 월간 분배 캘린더처럼 다시 올 이유가 있는 페이지.

## 3. 넘지 않는 선

수익 목표가 이 선을 넘을 이유가 되지 않는다. 하나라도 어기면 계정 단위 제재로 형제 사이트까지 함께 막힌다(AdSense 게시자 계정 공유).

- 무효 트래픽: 자기 클릭, 클릭 유도 문구, 트래픽 교환, 봇 방문, 자동화 브라우저로 운영 페이지 열기 금지
- 광고 과밀·오클릭 유도 배치(버튼·표 바로 옆, 콘텐츠보다 많은 광고) 금지
- 확장형 콘텐츠: 사람에게 쓸모없는 페이지를 양으로 찍어내지 않는다. 새 URL 주 상한(PUBLISHING.md §3)을 지킨다
- YMYL: 확인 안 된 수치, 확정수익·원금보장, 특정 종목 매수 권유 금지
- 저작권·이용약관: 데이터는 이용 조건을 확인한 출처만 쓰고 출처를 밝힌다
- 사용자 계정에 로그인하거나 가입·결제·게시를 대신하지 않는다(운영자가 한다)
